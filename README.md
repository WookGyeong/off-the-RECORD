# OTR — Off The Record

동네 골목과 오래된 가게에 숨은 이야기를, 걸으면서 오디오로 들려주는 **하이퍼로컬 오디오 가이드 앱**입니다.

![OTR 스크린샷](docs/screenshot.png)

## 이런 서비스예요

- 지도에서 내 주변의 "스팟"(동네 이야기가 있는 가게·골목)을 둘러볼 수 있어요.
- 스팟을 누르면 그 장소에 얽힌 이야기를 짧은 오디오로 들을 수 있어요.
- 여러 스팟을 이어 걷는 추천 "코스"를 따라 골목 산책을 할 수 있어요.
- 카테고리(동네 / 골목 / 문화·역사 / 카페·찻방)로 필터링해서 원하는 이야기만 골라볼 수 있어요.
- 내가 아는 골목이나 가게를 직접 스팟으로 등록할 수 있어요.
- 등록된 스팟을 제목/내용으로 검색해서 바로 지도에서 찾아볼 수 있어요.

## 주요 기능

- 실제 카카오맵 기반 지도 + 브라우저 위치 권한을 허용하면 내 현재 위치 표시
- 스팟 핀을 눌러 상세 설명과 오디오 미리듣기
- 여러 스팟을 묶은 추천 걷기 코스 열람
- 카테고리별 필터링
- **장소 검색으로 스팟 등록** — 카카오 장소 검색으로 실제 등록된 가게/장소를 찾아 정확한 좌표와 이름을 바로 채우거나, 지도를 직접 움직여 위치를 맞출 수 있어요. 핀 위치를 옮기면 그 근처와 가장 비슷한 실제 장소를 자동으로 추천해줘요.
- **스팟 검색** — 검색 범위(제목 / 내용 / 제목+내용)를 골라 등록된 스팟을 찾고, 목록에서 결과를 누르면 그 자리에 바로 미니 지도로 위치를 확인할 수 있어요.

## 기술 스택

- [Next.js](https://nextjs.org) 14 (App Router)
- React 18 + TypeScript
- Tailwind CSS
- [카카오맵 JavaScript SDK](https://apis.map.kakao.com)

## 시작하기 (로컬 개발)

1. 저장소를 내려받고 폴더로 이동
   ```bash
   npm install
   ```
2. 프로젝트 루트에 `.env.local` 파일을 만들고 카카오맵 JavaScript 키를 등록
   ```
   NEXT_PUBLIC_KAKAO_MAP_KEY=발급받은_카카오_JavaScript_키
   ```
   (키 발급 및 도메인 등록 방법은 [develop.md](develop.md) 참고)
3. 개발 서버 실행
   ```bash
   npm run dev
   ```
4. 브라우저에서 `http://localhost:3000` 접속

## 폴더 구조

```
app/                  Next.js 페이지 (화면 단위)
  page.tsx            메인 홈 화면 (지도 + 카테고리 필터 + 코스 목록 + 검색)
  add-place/page.tsx   장소 추가 화면 (장소 검색 + 지도 핀 + 이름/설명/카테고리 입력)
components/otr/       화면을 구성하는 UI 컴포넌트
  LocalMap.tsx         카카오맵 연동 지도 컴포넌트 (메인 화면)
  SpotSheet.tsx        스팟(가게) 상세 + 오디오 재생 바텀시트
  CourseSheet.tsx      추천 코스 상세 바텀시트
  SearchSheet.tsx      메인 화면 검색 바텀시트 (검색 범위 + 결과 목록 + 인라인 지도)
  SearchScopeDial.tsx  검색 범위(제목/내용/제목+내용) 선택 다이얼
  SearchResultMap.tsx  검색 결과 하나를 보여주는 미니 지도
  AddPlaceMap.tsx      장소 추가용 지도 (드래그로 핀 위치 조정 + 근처 장소 추천)
  PlaceSearch.tsx      카카오 실제 장소 검색(장소 추가 화면용)
data/otr/              스팟, 코스 데이터
  spots.ts             동네 스팟 목록 (위치, 카테고리, 설명, 오디오 길이)
  courses.ts           추천 걷기 코스 목록
```
